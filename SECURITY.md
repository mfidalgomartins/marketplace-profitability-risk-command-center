# Security Policy

## Scope and data

This repository is a self-contained analytics demonstration. **All data is
synthetic and deterministic** — it is generated by
`src/data_generation/generate_synthetic_marketplace_data.py` and contains no
real buyers, sellers, payment instruments, or personally identifiable
information. There are no secrets, credentials, API keys, or external network
calls in the codebase or pipeline.

The outputs are not suitable for production fraud decisions, seller enforcement,
or financial reporting without real data and external validation. See the
[methodology](docs/methodology.md) for analytical limitations.

## Automated checks

Security is enforced on every change:

- **`bandit`** scans `src/` for common Python security issues
  (`make security`). The only subprocess use is the pipeline runner, which
  executes a fixed list of in-repo scripts with no shell and no untrusted input;
  it is annotated and reviewed.
- **`pip-audit`** checks pinned dependencies against known CVEs
  (`requirements.txt` / `requirements-dev.txt`).
- Dependencies are fully pinned for reproducible, auditable builds.

## Reporting a vulnerability

If you believe you have found a security issue, please open a GitHub issue, or
contact the maintainer privately if the report contains sensitive details.
Please include steps to reproduce and the affected file(s). We aim to
acknowledge reports within a few days.
